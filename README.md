# Fortune Cookie Wisdom for Developers

One line (117 characters, limit 120): an original fortune-cookie line for a software developer — the deploy you dread, the estimate you gave, a quiet twist at the end.

> The deploy you dread will pass; the estimate you gave will not. Breathe — the code forgives what the calendar cannot.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
